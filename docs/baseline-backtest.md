# UEL baseline backtest

Запуск 2026-08-17 на локальной исследовательской БД:

```bash
DATABASE_URL=sqlite+aiosqlite:///data/research.sqlite3 \
  uv run python -m app backtest \
  --source uel_ef \
  --min-samples 20 \
  --train-days 8 \
  --validation-days 4 \
  --test-days 4 \
  --step-days 4
```

## Данные и разбиение

- 2983 завершённых матча UEL eFootball;
- период: 2026-07-24 — 2026-08-17;
- 2664 события прошли `min_samples=20`, 319 осталось warm-up;
- три rolling fold;
- общая непересекающаяся out-of-sample часть: 1460 событий;
- на каждом событии используются только результаты с
  `source_updated_at < event.started_at`.

## Out-of-sample результаты 1X2

| Модель | LogLoss | Brier | Calibration error | Accuracy |
|---|---:|---:|---:|---:|
| individual + H2H, fixed weights | 1.0704 | 0.6470 | 0.0166 | 40.96% |
| player frequency | 1.0726 | 0.6486 | 0.0187 | 40.14% |
| Poisson goals | 1.0733 | 0.6489 | 0.0181 | 40.55% |
| recent 10/30/all, fixed weights | 1.0869 | 0.6584 | 0.0334 | 38.49% |
| uniform 1/3 | 1.0986 | 0.6667 | 0.0011 | 33.22% |

Дополнительно одним и тем же walk-forward протоколом проверены фиксированные окна
`5, 10, 20, 25, 30, 50, 75, 100, 200` и `all-time`, отдельно для индивидуальной
формы и H2H. Лучшие результаты по LogLoss:

| Окно/модель | LogLoss | Brier | Calibration error | Accuracy |
|---|---:|---:|---:|---:|
| all-time player frequency | 1.0726 | 0.6486 | 0.0187 | 40.14% |
| player last 200 | 1.0728 | 0.6487 | 0.0185 | 40.00% |
| player last 100 | 1.0785 | 0.6522 | 0.0178 | 39.93% |
| player last 75 | 1.0786 | 0.6524 | 0.0215 | 39.45% |
| H2H last 75 | 1.0872 | 0.6558 | 0.0497 | 40.68% |

Короткие окна оказались заметно хуже: player last 5 — LogLoss 1.1425, H2H last 5 —
1.1586. На этом корпусе нет подтверждения гипотезы, что одно короткое фиксированное
окно лучше долгосрочной статистики. Лучшим всё равно остаётся интерпретируемый blend
individual + H2H с заранее фиксированными весами.

`individual + H2H` имеет лучший суммарный LogLoss, но нестабилен по fold:

- fold 1: 1.0750;
- fold 2: 1.0459;
- fold 3: 1.0895.

Следовательно, baseline содержит predictive signal относительно uniform, но выборка
короткая и ухудшение на последнем fold запрещает утверждать устойчивость стратегии.
Низкий calibration error uniform не означает полезность: постоянная вероятность
1/3 по определению близка к общей доле наиболее вероятного класса, но не различает
события.

## Чего этот отчёт не доказывает

- это не betting backtest;
- нет ROI/yield/CLV: семь базовых factor ID уже подтверждены, но собственной линии
  ещё нет на всём историческом интервале исходов;
- fixed weights не подбирались по test, но и не оптимизировались на train;
- выборка охватывает около 24 дней и одну экосистему UEL;
- утверждать прибыльность или статистическую значимость стратегии нельзя.
