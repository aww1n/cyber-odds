# Reverse-engineering dataset

`../known_alerts.json` хранит только наблюдаемые поля. Вычисляемые значения не следует
вносить туда вручную: команда `python -m app research-alerts` пересчитывает их и создаёт
таблицы в `../output/`.

## Классы доказательств

- `verified_alert` — прочитан из исходного сообщения/скриншота, у которого сохранён путь
  или иной проверяемый источник;
- `specification_example` — полный числовой пример из ТЗ;
- `formula_example` — неполный пример, пригодный лишь для проверки одной формулы.

Только `verified_alert` допустим как строка будущего датасета
`features_before_match → P_target`. Примеры из спецификации нельзя использовать для
оценки модели или ROI.
